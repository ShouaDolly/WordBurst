How to Play

Start on a letter, draw through touching tiles, and release. WordBurst checks the word automatically.

↗️
Move in any directionUp, down, sideways, diagonally, and sharp criss-cross turns all work.
⏱️
3 minute roundFind as many words as you can before time runs out.
🔤
3 letters minimumYou cannot reuse the same tile within one word.
💥
Each extra letter scores more3 letters: 1 point · 4: 2 · 5: 3 · 6: 4 · and so on.
🏁
Best of threeReplay the exact puzzle up to three total attempts, then share it so friends can try the same board.
